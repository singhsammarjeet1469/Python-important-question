# Python-important-question
This repository contains beginner-friendly Python programs that help in learning basic programming concepts such as conditional statements, user input, operators, and decision making.
Programs Included
Greatest of Four Numbers
Takes four integer inputs from the user.
Finds and displays the greatest number.
Student Percentage & Pass/Fail Checker
Takes marks of three subjects.
Calculates the total percentage.
Uses if-else statements to determine whether the student has passed or failed.
Scam Keyword Checker
Stores predefined values in variables (p1 to p4).
Accepts user input.
Checks whether the input matches any of the predefined values.
Displays "Scam" if a match is found; otherwise displays "Not a Scam".

Variables
User Input
Data Types
Conditional Statements (if, elif, else)
Comparison Operators
Logical Operators
