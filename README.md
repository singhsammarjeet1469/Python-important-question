# Python Practice Programs

A collection of beginner Python programs created while learning Python.

##  Programs Included

### 1. Greatest of Four Numbers
- Takes four numbers as input.
- Finds the greatest number using if-elif-else.

**File:** `prob1.py`

---

### 2. Student Pass or Fail
- Takes marks of three subjects.
- Calculates percentage.
- Checks whether the student passes or fails.

**Conditions**
- Overall percentage must be greater than 40%.
- Minimum 33 marks in every subject.

**File:** `prob2.py`

---

### 3. Spam Message Checker
Checks whether a message contains spam words like:

- Make a lot of money
- Buy now
- Subscribe this
- Click this

If any keyword is found, the program prints **"This is spam."** Otherwise, it prints **"Not spam."**

**File:** `prob3.py`
